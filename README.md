# 工作完成標準產生器 Done Criteria — Claude Skill

要求說得太簡單，AI 做出來常常不是你要的。這個 Skill 讓 AI 開工前先把你的要求改寫成可以檢查的完成標準，你確認後才動手。

## 怎麼用
- 把要求拆成：要做什麼、不改什麼、完成標準、要先問的問題。
- 每條完成標準都寫怎麼查（看檔、跑指令、看畫面）；不自己加條件。
- 給你確認後才開工。

## 限制
- 還沒有實際使用紀錄。
- Skill 內容是繁體中文。
- 不保證一定有效；AI 不一定每次都照做。
